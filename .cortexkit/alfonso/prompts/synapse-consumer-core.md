ONE CONTRACT DELTA newer than the spec (absorb): Synapse error typing is now stricter — deterministic artifact/load failures are PERMANENT (`artifact_invalid`, retryable=false); every transient error carries `retry_after_ms`. Honor retry_after_ms in backoff, treat permanent as circuit-open (no retry, log + fall back per fallback_provider).

RUNTIME NOTE: the live gte lane IS certified and servable (model_id gte-modernbert-base-f16, dims 768, table_epoch 0). Build and test against mocks regardless (unit tests never talk to the daemon). Do NOT hardcode any fingerprint value in code: fingerprints are read from models.list at runtime and persisted at registration (F5). Two live behaviors to model in the provider: module restarts drop loaded models to unloaded, so the first embed after a restart may return the transient model-loading error carrying retry_after_ms (retry lane handles it; no reload op exists or is needed); models.list serves a live recommended_batch field, prefer it over any hardcoded batch size. A served fingerprint differing from the registered one is the hard-reject path per F5: refuse to serve or save, log loud; never adapt.
